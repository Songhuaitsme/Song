# 内容与媒体管理

摄影系列、随笔和收藏都使用 `draft | private | public`：草稿与私藏只有管理员能看到，访客直接访问会得到 404；公开内容和其图片可被访客读取。单张摄影作品继承系列权限。

工作室提供摄影、随笔、收藏、关于、首页文案、媒体库和同步冲突七个区域。删除内容会留下 30 天同步墓碑，而不是立即物理删除，避免另一端在同步时重新创建。

`media-source` 保存原图且不提交 Git。执行 `npm run media:import` 会扫描 JPG/PNG/WebP，保留原图、生成最长边 2200px 的 WebP、计算 SHA-256 去重，并以 `private + unassigned` 写入媒体库。未关联图片不会自动出现在公开页面。

公开图片允许公共缓存；草稿、私藏和未关联媒体只能由管理员读取并使用 `no-store`。
