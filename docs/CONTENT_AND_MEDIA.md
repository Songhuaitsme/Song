# 内容与媒体管理

摄影系列、随笔和收藏都使用 `draft | private | public`：草稿仅管理员可见，访客直接访问会得到 404。私藏向访客展示标题、随笔摘要、系列简介或收藏分类；点击后展示私藏提示，正文、照片、收藏短评与来源链接在服务端移除，仅主人视图可读取完整内容。公开内容和其图片可被访客读取。单张摄影作品继承系列权限。

工作室提供摄影、随笔、收藏、关于、首页文案、媒体库和同步冲突七个区域。删除内容会留下 30 天同步墓碑，而不是立即物理删除，避免另一端在同步时重新创建。

`media-source` 保存原图且不提交 Git。执行 `npm run media:import` 会扫描 JPG/PNG/WebP，保留原图、生成最长边 2200px 的 WebP、计算 SHA-256 去重，并以 `private + unassigned` 写入媒体库。未关联图片不会自动出现在公开页面。

浏览器工作室默认在本机压缩后上传：均衡模式最长边 2200px、目标 800KB。也可选择更小体积、更多细节或保留原图；本地文件不会被修改。摄影、随笔、媒体库共用该设置。压缩后的 WebP 与展示图字节相同时，R2 直传只传输并保存一个对象，两种引用使用同一展示地址，服务端仍验证大小、类型与 SHA-256。历史原图与命令行导入不受该浏览器设置影响。

公开图片允许公共缓存；草稿、私藏和未关联媒体只能由管理员读取并使用 `no-store`。
