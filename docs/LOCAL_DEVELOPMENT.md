# 本地开发

需要 Node.js 22.13+ 和 npm，不需要 Docker、独立 SQLite 或本机对象存储服务。

1. 运行 `npm install`。
2. 运行 `npm run setup`，按提示输入管理员账号和密码。
3. 运行 `npm run dev`。
4. 浏览 `http://127.0.0.1:5173`，登录入口是 `/login`。

## Windows 双击预览（无需打开终端）

完成上面的首次安装和初始化后，日常开发只需：

1. 双击项目根目录的 **`启动网站.vbs`**。服务在后台运行，不显示终端；网页就绪后会自动在默认浏览器中打开 `http://127.0.0.1:5173/`。第一次启动可能需要等待一两分钟。
2. 用编辑器修改页面、组件或样式源码并保存，浏览器会自动更新。源码有编译错误时，先按页面提示修复并保存。修改环境变量或启动配置后，停止服务再重新启动。
3. 关闭浏览器不会停止服务。用完双击 **`停止网站.vbs`**，停止后台预览；下次可再次双击启动。

重复双击启动会复用本项目服务，不会重复创建后台进程。若已有通过 `npm run dev` 启动的本项目服务，入口会复用它，但“停止网站”不会停止它，请在原终端按 `Ctrl+C`。端口 5173 被其他程序占用时会弹窗提示，不会改用其他端口。

启动失败会弹窗说明。日志位于 `var/preview/`：`launcher.log` 记录启动和停止结果，`stdout.log` 与 `stderr.log` 记录最近一次后台服务运行的输出。运行记录和日志已由 Git 忽略。

这两个入口使用 Windows Script Host 和系统自带的 Windows PowerShell。若系统禁用了 `.vbs`，请使用上面的终端启动方式。无需设置开机自启。

本地保存源码只更新本地预览。确认效果后，按 [发布与回滚](DEPLOYMENT.md) 完成检查，再通过已有 Codex/Sites 流程上线；本地内容和图片仍按现有同步流程处理。

开发者验证启动入口时，先停止端口 5173 上的服务，再运行 `powershell -NoProfile -ExecutionPolicy Bypass -File test/local-preview.test.ps1`。测试在 `var/preview-tests/` 的独立目录中检查启动、复用、停止、重启、进程身份保护和错误清理，不读取正式项目的账号配置。

本地 D1/R2 数据由 Wrangler 保存于 `.wrangler/state`。停止或重启进程不会丢失。`.env.local`、`.wrangler`、`var` 与 `media-source` 都不会提交到 Git。

本地 HTTP 会自动省略 Cookie 的 `Secure` 属性；线上 HTTPS 始终使用 `HttpOnly + Secure + SameSite=Lax`。认证会话七天无操作过期，修改账号或密码会让旧会话失效。

界面设置位置：

- 品牌、导航、SEO 和功能开关：`src/config/site.ts`
- 字体、颜色、留白、内容宽度和动效：`src/frontend/styles/tokens.css`
- 页面内容：登录 `/studio` 后编辑，不需要重新构建

品牌、导航与按钮文字可在主人视图点旁边的“编辑”，或在工作室的“页面文字与字体”中保存。`src/config/site.ts` 的 `defaultCopy` 只提供默认文字，已保存的文字优先，清空文字也不会被默认值覆盖。

## 全站文字标准

登录工作室，打开“文字标准”（`/studio?tab=typography`），按页面和文字用途调整字体、基准字号、颜色、字重。这里覆盖公开页面及共用导航、页脚；工作室和登录表单使用独立排版。文案内容继续在原来的各栏目编辑。

首页标题基准为 90 / 50 / 25px，简介、摘要及收藏说明统一为黑体 20px。桌面端保留 1.3 倍关系，20px 实际显示为 26 CSS px。手机按各用途原有响应式比例缩小，不会直接使用桌面的大标题字号。其他页面字号为 0 时沿用该用途的响应式默认值；页面显示的实际字号也会受浏览器缩放影响。

选择桌面或移动样例检查效果，再保存；“取消修改”回到上次保存值，“恢复该组标准”回到已确认的默认值。颜色支持常用色板、取色器及六位 HEX，例如 `#365f83`。行距、字距和布局保持原设置。

摄影目录与摄影详情页封面均采用底部居中、文字居中的排版：桌面底部留白 56px，手机 36px；底部渐变衬托白字。两页的封面主标题、标签与数量共用字体、字号、颜色和字重；在任一页修改或恢复对应标准，另一页同步更新。标题桌面默认 `clamp(44px, 5.9vw, 88px)`、手机 `clamp(34px, 9.8vw, 44px)`，标签、照片数量和署名分别为 15px / 12px。在“文字标准 → 摄影目录 / 摄影详情”中可切换实际系列查看整块封面预览。两页和预览共用 `src/shared/story-cover-standard.ts` 的排版定义。旧设置中两页封面标准不一致时，以摄影目录为共用来源；单条文字覆盖仍按对应页面和用途独立保存。

首次点击“应用并保存标准”后启用新版格式。原来的 `typography` 和 `textFormats` 保留在设置中作为旧格式归档，启用后不再参与公开页面渲染；读取页面不会自动启用或改写数据库。新版配置位于 `SiteCopy.textStandards`，版本为 2，仍通过 `/api/studio` 保存到 `site_settings` 的 `site_copy_v1`，同步、备份、恢复沿用已有流程。

主人视图中单条文字的“编辑”默认跟随标准。主动设置格式后，只覆盖当前页面中的这一用途：例如首页标题不会改变摄影详情页标题或结束标签。点击“恢复跟随标准”并保存可删除该处覆盖。改文字内容仍会更新同一条内容。

## 摄影系列批量上传

登录工作室，在“摄影”中展开目标系列，点击下方“批量上传照片”。选择文件时按住 `Ctrl` 多选，或按住 `Shift` 连选。支持 JPEG、PNG、WebP，每张最多 25MB。

图片会逐张处理、上传并自动保存到当前系列末尾；上传列表显示每张的状态和进度。某张失败不会中断其他图片，点击“重试失败项”只处理未完成的照片。新建系列会先自动保存，无封面时使用第一张成功上传的照片作为封面。

上传后可继续编辑照片注释、地点和日期，或用箭头调整顺序。原图保留，展示图最长边不超过 2200 像素。本地上传仍只影响本地数据，上线与图片同步沿用现有流程。
