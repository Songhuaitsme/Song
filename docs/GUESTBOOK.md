# 留言板

公开地址 `/guestbook`，桌面及手机导航中的“留言”位于“关于”之前。访客无需登录，仅填写昵称（1～30 字）和留言（1～1000 字），提交后直接公开。内容保留分段，以纯文本展示，不解析 HTML 或图片附件。

工作室 `/studio?tab=messages` 独立加载留言，提供状态筛选、昵称及正文搜索、每页 20 条、主人回复、隐藏、重新公开和删除。每条仅保留一条主人回复（最多 2000 字），清空并保存会移除回复；隐藏留言同时隐藏回复。访客原文不能在工作室改写。回复草稿在本次工作室访问期间跨筛选、分页、栏目保留，离开页面会提醒；可确认放弃草稿。

## API 与并发

- `GET /api/messages?page=1` 仅返回未删除的公开留言及主人回复，按创建时间、ID 倒序，每页 20 条，禁止缓存。内部状态、版本、防刷标识不下发。
- `POST /api/messages` 接收 `{ id, nickname, body, website: "" }`。客户端为每次内容生成 UUID，网络失败保留 ID，重试同一内容不会重复发布；同 ID 不同内容返回 409。返回 `{ ok, id, message }`，已隐藏或删除记录重试时 `message` 为 `null`。
- `GET /api/studio/messages?page=1&visibility=all&q=` 要求管理员会话，返回管理字段、筛选结果、分页和所有状态数量。
- `POST /api/studio/messages` 要求管理员会话和 CSRF，接收 `id`、`version`，以及 `action: "reply"` 和 `reply`、`action: "set-visibility"` 和 `visibility`，或 `action: "delete"`。过期版本返回 409，不覆盖新回复。原文及昵称不接受修改。

提交要求同源 JSON，请求体最多 16 KiB，并检查隐藏诱饵字段。来源通过 `SESSION_SECRET` 加用途前缀做 HMAC，不信任任意 `X-Forwarded-For`，不保存原始 IP。本地无 Cloudflare 来源头时使用开发标识。

每来源滚动 60 秒最多 1 条、滚动 24 小时最多 10 条，并拦截同来源 24 小时内的重复正文（合并空白后比较摘要）。返回 429 和 `Retry-After`。短期提交记录清理、限频准入与正式留言写入在一个 D1 batch 事务内完成；失败不消耗次数，不产生半条记录。

## 数据、同步与部署

`0006_guestbook.sql` 新增 `guestbook_messages` 和 `guestbook_submissions`；留言使用版本号、更新时间和软删除。短期来源及内容散列只存于辅助表，不进入公开 API、内容备份或同步。辅助表过期数据在提交时清理。

同步结构版本升级至 7，留言、回复、隐藏和删除状态参与备份、恢复及冲突管理；冲突处理拒绝覆盖之后的新编辑。版本 3～6 的备份未包含留言时，不删除目标端已有留言。

发布前备份本地和线上数据，分别应用迁移，并更新两端代码；旧版客户端同步会被结构版本检查拒绝。验证公开留言、主人回复及隐藏后，删除测试留言并清理其辅助记录。页面标题、介绍和导航文案可在工作室修改，留言页文字接入文字标准。
